# PloinkysMOBAGameServer

This is the game server application for PloinkysMOBAGame.

## Prerequisities

- Blender 4.4 (blender.exe on PATH)
- A C++ 20 compiler
- CMake 3.28

## Developer setup

1. Clone the repo
1. Initialize submodules (`git submodule update --init`)
1. Download the [steam sdk](https://partner.steamgames.com/downloads/steamworks_sdk_162.zip)
1. Extract the content of the "sdk" folder into Vendor/steam
